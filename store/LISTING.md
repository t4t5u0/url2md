### 概要（132 文字以内）

```
開いているタブを Markdown のリンク記法でコピーします。Amazon の長い URL の最小化と、utm_ 等のトラッキングパラメータ除去に対応。
```

### 詳細な説明

```
url2md は、いま見ているページを Markdown のリンク記法でクリップボードにコピーする、
ただそれだけの拡張機能です。

■ 使い方
ツールバーの url2md アイコンをクリックするだけです。

    [ページタイトル](https://example.com)

がクリップボードに入ります。あとは README、Issue、Scrapbox、Obsidian、Notion など
Markdown が使える場所に貼り付けてください。

ページにスクリプトを注入しない作りなので、chrome:// で始まる Chrome の内部ページでも
そのままコピーできます。

■ 余計なパラメータを落としてからコピー
Amazon の商品ページは https://www.amazon.co.jp/dp/ASIN の形まで最小化します。
utm_source などのトラッキングパラメータ、?ref= のようなリファラーパラメータ、
X の ?s=20&t=... や YouTube の ?si=... も除去します。
どちらの機能もデフォルトで有効で、オプション画面から個別にオフにできます。

    変換前 https://www.amazon.co.jp/Echo-Dot/dp/B09B8VGCR8/ref=cm_sw_r_apan_dp_XYZ?th=1
    変換後 https://www.amazon.co.jp/dp/B09B8VGCR8

GitHub / GitLab のようにブランチ名として ?ref= を使うサイトや、YouTube の再生位置 ?t= は
意味のある値なので残します。

■ 画像 URL は画像記法に
.png / .jpg / .jpeg / .gif / .webp / .avif / .bmp / .svg で終わる URL を開いている場合は、
先頭に ! が付いた画像記法になります。

    ![タイトル](https://example.com/image.png)

■ 記号のエスケープ
タイトルに [ ] が含まれる場合や、URL に括弧・空白が含まれる場合も記法が壊れないよう
自動でエスケープします（括弧を含む URL は <...> で囲みます）。

■ コピー結果がすぐわかる
コピーに成功するとアイコンに緑のチェックが、コピーできないページ（chrome:// や
Chrome ウェブストアなど、拡張機能が動作できないページ）では赤い ! が一瞬表示されます。

■ プライバシー
閲覧データの収集・保存・外部送信は一切ありません。ネットワーク通信も行いません。
必要な権限は activeTab / storage / offscreen / clipboardWrite のみです。activeTab は
アイコンをクリックしたその瞬間のタブにしか作用せず、storage は設定のオン・オフを覚えるため、
残りの 2 つはクリップボードへ書き込むためだけに使います。閲覧履歴にはアクセスしません。

ソースコードは MIT ライセンスで公開しています。
https://github.com/t4t5u0/url2md
```

## 3. プライバシー タブ（審査で一番よく差し戻される箇所）

### 単一用途の説明

```
現在アクティブなタブのタイトルと URL を Markdown のリンク記法に変換し、
クリップボードへコピーすること。これが本拡張機能の唯一の機能です。
```

### activeTab の権限が必要な理由

```
ツールバーのアイコンがクリックされたときに限り、そのタブのタイトルと URL を取得するために
使用します。この 2 つの値が Markdown リンクの生成に必要な唯一の情報です。
ユーザーが明示的にアイコンをクリックしない限り、いかなるタブの内容にもアクセスしません。
ホスト権限は要求していません。
```

### offscreen の権限が必要な理由

```
Manifest V3 の service worker には DOM もクリップボード API も存在しないため、
クリップボードへの書き込みができません。そこで chrome.offscreen を使い、
クリップボードへ書き込むためだけの非表示ページを一時的に開いています。
このページは書き込み後ただちに閉じられ、ネットワーク通信も DOM の読み取りも行いません。
```

### clipboardWrite の権限が必要な理由

```
上記の非表示ページ内で document.execCommand("copy") を実行してクリップボードへ
書き込むために必要です。書き込むのは生成した Markdown リンクの文字列のみで、
クリップボードの読み取りは行いません。
```

### storage の権限が必要な理由

```
オプション画面の 2 つのチェックボックス (Amazon URL の最小化 / トラッキングパラメータの除去) の
オン・オフ状態を保存するためだけに使用します。保存されるのは真偽値 2 つのみで、
閲覧した URL やページの内容は一切保存しません。
```

### リモートコードの使用

**「いいえ、リモートコードは使用していません」** を選択。

### データの使用（すべて「収集しない」）

本拡張機能はいかなるカテゴリのユーザーデータも収集しません。
（設定値の chrome.storage.sync への保存は「ユーザーデータの収集」には該当しません。
端末内・利用者自身のアカウント内に留まり、開発者は参照できないためです）
チェックボックスはすべて未チェックのまま、以下の 3 つの証明にチェックを入れます。

- [ ] 承認された用途以外でのデータの販売・譲渡を行っていない
- [ ] 本アイテムの単一目的と関係のない用途にデータを使用・転送していない
- [ ] 信用力の判断や融資目的でデータを使用・転送していない

## バージョンを上げて再提出するとき

1. `package.json` と `public/manifest.json` の `version` を揃えて上げる
2. `npm run zip`
3. Dashboard の「パッケージ」タブから新しい zip をアップロードして再提出

> `manifest.json` の `version` は一度公開すると同じ値を再アップロードできません。

## 掲載画像を作り直すとき

`assets/` に生成元の SVG / HTML があります。ヘッドレス Chrome でレンダリングして PNG 化しています
（`assets/screenshot-options.html` は設定画面を iframe で埋め込んでいるため、
`dist` を HTTP で配信した状態で開く必要があります）。
