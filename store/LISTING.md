### 概要（132 文字以内）

```
開いているタブのタイトルと URL を、ワンクリックで Markdown のリンク記法としてコピーします。画像 URL の場合は画像記法になります。
```

### 詳細な説明

```
url2md は、いま見ているページを Markdown のリンク記法でクリップボードにコピーする、
ただそれだけの拡張機能です。

■ 使い方
ツールバーの url2md アイコンをクリックするだけです。

    [ページタイトル](https://example.com)

がクリップボードに入ります。あとは README、Issue、Scrapbox、Obsidian、Notion など
Markdown が使える場所に貼り付けてください。

■ 画像 URL は画像記法に
.png / .jpg / .jpeg / .gif / .webp / .avif / .bmp / .svg で終わる URL を開いている場合は、
先頭に ! が付いた画像記法になります。

    ![タイトル](https://example.com/image.png)

■ 記号のエスケープ
タイトルに [ ] が含まれる場合や、URL に括弧・空白が含まれる場合も記法が壊れないよう
自動でエスケープします（括弧を含む URL は <...> で囲みます）。

■ コピー結果がすぐわかる
コピーに成功するとアイコンに緑のチェックが、コピーできないページ（chrome:// や
Chrome ウェブストアなど、拡張機能が動作できないページ）では赤い ! が一瞬表示されます。

■ プライバシー
データの収集・保存・外部送信は一切ありません。ネットワーク通信も行いません。
必要な権限は activeTab と scripting のみで、どちらもアイコンをクリックした
その瞬間のタブにしか作用しません。閲覧履歴にはアクセスしません。

ソースコードは MIT ライセンスで公開しています。
https://github.com/t4t5u0/url2md
```

## 3. プライバシー タブ（審査で一番よく差し戻される箇所）

### 単一用途の説明

```
現在アクティブなタブのタイトルと URL を Markdown のリンク記法に変換し、
クリップボードへコピーすること。これが本拡張機能の唯一の機能です。
```

### activeTab の権限が必要な理由

```
ツールバーのアイコンがクリックされたときに限り、そのタブのタイトルと URL を取得するために
使用します。この 2 つの値が Markdown リンクの生成に必要な唯一の情報です。
ユーザーが明示的にアイコンをクリックしない限り、いかなるタブの内容にもアクセスしません。
ホスト権限は要求していません。
```

### scripting の権限が必要な理由

```
Manifest V3 の service worker には DOM とクリップボード API が存在しないため、
クリップボードへの書き込みができません。そこで、アイコンがクリックされたタブに対してのみ
クリップボードへ書き込む短いスクリプトを注入するために scripting を使用しています。
注入するコードは拡張機能パッケージに同梱されており、リモートコードは一切実行しません。
対象は chrome.scripting.executeScript の tabId で指定した当該タブ 1 つに限定されます。
```

### リモートコードの使用

**「いいえ、リモートコードは使用していません」** を選択。

### データの使用（すべて「収集しない」）

本拡張機能はいかなるカテゴリのユーザーデータも収集しません。
チェックボックスはすべて未チェックのまま、以下の 3 つの証明にチェックを入れます。

- [ ] 承認された用途以外でのデータの販売・譲渡を行っていない
- [ ] 本アイテムの単一目的と関係のない用途にデータを使用・転送していない
- [ ] 信用力の判断や融資目的でデータを使用・転送していない

## バージョンを上げて再提出するとき

1. `package.json` と `public/manifest.json` の `version` を揃えて上げる
2. `npm run zip`
3. Dashboard の「パッケージ」タブから新しい zip をアップロードして再提出

> `manifest.json` の `version` は一度公開すると同じ値を再アップロードできません。
